# Bug Runner — 跑酷肉鸽游戏

一款横版跑酷 + Roguelite 独立游戏。你是建模软件中一个被程序错误赋予了速度的初始方块，在崩溃的操作系统中逃亡，通过拾取"破损系统文件碎片"获得新能力。

> 持续迭代开发中 · Python 3.12 + Pygame 2.6.1

## 核心机制：属性即能力

方块初始只有一个属性 —— `X Speed: 200`。其余所有能力（重力、跳跃、碰撞、鼠标、场景编辑）都需要在路上拾取"系统文件碎片"来激活。


属性可被新碎片覆盖、被恶意程序删除、被稀有道具重置。**肉鸽的随机在属性组合，不在数值**——每局的可用工具组合决定玩法体验。





## 已实现功能

- **物理系统**：Delta Time 帧率无关、重力、穿越法碰撞检测、防二段跳状态机
- **世界生成**：平台无限滚动、两级坑洞、浮空平台、多层掉落路线（掉落不死）
- **摄像机**：弹簧跟随 + 落点预测 + 死区防抖
- **粒子系统**：通用发射器，摩擦 / 落地 / 金币
- **背景系统**：建模软件视口风格，预渲染网格 + 无缝滚动
- **UI**：建模软件风格 Properties Panel 属性面板
- **显示**：全屏 + 基准的动态缩放

## 架构

```
main.py         主入口（游戏循环、事件、绘制调度）
config.py       常量与参数（屏幕、物理、生成概率）
player.py       Player（物理、跳跃、碰撞、属性开关）
camera.py       Camera（弹簧摄像机）
world.py        World（平台/金币/障碍物生成与碰撞）
particles.py    粒子系统（通用发射器 + 三种特效）
background.py   背景（预渲染网格 + 滚动）
game_ui.py      Properties Panel
```
